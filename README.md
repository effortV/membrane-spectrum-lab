# 膜谱研究台 · Membrane Spectrum Lab

面向 NF／RO 膜的制备—XPS—结构—性能研究助手。系统读取原始数据与文献，提出可计算、可证伪的新 XPS 描述符，开展文献分组验证；不会导入 final 的旧模型或 R²，也不会把 HABD／HCD／HAD 的重命名当作新发现。

## Streamlit Community Cloud

云端入口为 `streamlit_cloud.py`，分支 `main`，通过 `requirements.txt` 安装轻量 UI／SSH 依赖。数据、数据库和计算保留在 Windows 服务器，云端通过固定主机指纹的加密 SSH 隧道访问仅监听回环地址的 FastAPI。配置模板见 `.streamlit/secrets.example.toml`，实际凭据只放 Streamlit Secrets；GitHub 中不包含文献、NF／RO 数据或密钥。连接未配置时页面明确提示，不创建云端替代数据库。详细步骤见 `deployment/SSH_FASTAPI.md`。

## 文献读取与进度

“文献中心 → 读取待处理文献”依次索引、读取本地文字、筛选 XPS 图页，不调用 LLM。“证据与智能体 → 开始页级证据抽取”须确认后才调用视觉模型。

索引、解析、计划、下载、读图、候选、问答和 ML 都在后台执行。任务栏每两秒显示当前文献／页码、完成数、耗时、模型等待或训练折数；换页不重复提交。完成结果保留在会话，证据／运行报告保存在服务器。重启会结束尚在运行的线程，成功页检查点可恢复；停止按钮阻止后续工作，不承诺取消已发出请求的供应商计费。

API 检索与可访问 PDF 下载使用 OpenAlex／Elsevier；权限不足进入人工补充清单，由用户上传。下载限速、暂时失败重试、来源独立的断点续取和公开 URL 校验继续保留。

## 模型等待与超时恢复

主模型与读图均默认使用 SSE 流式接收。后台显示正在等待、推理或生成、已收到段数及字符数，不显示推理正文；回答完全返回后才校验和保存，断流的半截结果不会作为成功缓存。工具调用的增量参数在完整返回后拼接，不在收到半截参数时执行。

在“系统设置 → 模型等待与重试”调整并保存：主／视觉模型连续无数据等待默认 600 秒，可调至 1800 秒；单次请求协作总时限默认 1800 秒，模型批次默认 3600 秒。总时限在数据到达时检查，阻塞读取仍受无数据等待上限约束。正在运行任务的设置不改变，也不会因为保存／刷新而重发。

主模型与视觉模型的超时／断流重试分别设置，默认关闭。明确勾选授权后，最多额外重试 1 次；这不是恢复同一请求，仍可能重复计费，也受本次请求预算和批次时限约束。连接建立错误及 HTTP 429／5xx 等保留有限重试。失败请求显示追踪 ID，便于平台查日志，不保存凭据。

本次修复不自动重跑历史付费失败任务。候选生成请重新确认提交；读图选择“仅重试失败文献”，成功页检查点会跳过。批次中断、取消或预算上限不等于科学失败，已完成证据不删除。

## 关系研究（ML）

主要研究关系：

- 制备 → XPS
- 制备 + XPS → 独立测得的结构
- XPS → 独立测得的结构
- XPS → 性能
- 独立结构 → 性能
- 制备 + XPS + 结构 → 性能

层级表头优先决定变量类别：基膜 MWCO 是制备信息，分离层 MWCO 属于结构，R(NaCl) 等截留率属于性能，进料浓度／压力属于测试条件。HABD、DNC／交联度等是 XPS 推导的代理量，不用于循环验证 XPS → 独立结构。浓度单位分别保留；不会把 wt%、w/v%、g/L 直接合并，也不会把已经按压力归一化的通量重复除以压力。

支持单体、基膜材料等文本类别与数值变量。编码、填补、缩放和调参仅使用各训练折。同一 DOI 不跨训练与验证。默认排除 DOI 未解析的行、仅保留选定 XPS／结构有测量的样本；开启备用分组或填补仅供探索。

同一目标、同一样本、同一外层折比较单变量组／组合组、共同测试条件及训练均值基线。保存逐样本未见文献预测、R²、MAE、RMSE、Spearman、逐文献平均误差、内层参数、源行 ID、数据／代码／切分哈希。低或负 R² 保留，不自动筛出漂亮结果。组合比较不等于因果或中介分析，多次挑选仍须外部验证。

## XPS 图分析

上传同一样品 1–4 张 PNG／JPEG／单页 TIFF，并填写膜体系、材料、制备及已有独立测量。原图内容哈希归档，不会覆盖原始 Excel。

Qwen/Qwen3-VL-32B-Instruct 提取图中可见轴、谱类型、明确可读标注及不确定性；deepseek-ai/DeepSeek-V4-Pro 根据实际文献证据和实验条件给出化学归属、结构关联、性能趋势假说、其他解释和验证实验。报告保留 DOI、PDF 页码和证据 ID，未知引用拒绝发布。报告、图像或模型读数不会自动进入 ML。

图像不能替代峰拟合和独立性能测试。分别归一化的 N/O 谱不能计算跨元素化学计量，干态 XPS 不自动证明湿态电荷、孔径、交联度或绝对通量／截留率。文献抽取与解释仍需人工核验。

## 后台任务

左侧“后台任务”集中显示当前任务、阶段、具体文献／PDF 页码／ML 训练折数、模型等待上限和耗时，每 2 秒更新。只能停止本会话发起任务的后续步骤，已发出的请求仍可能计费。切换页面或查看进度不会重发请求。

历史记录保存在 `D:\data\XPS-agent\workspace\state\tasks`，包含阶段轨迹和数量摘要，不保存密钥、问题、提示词或模型回答。可筛选状态、查看详情、下载任务记录并跳转到对应结果页面。旧历史没有数量摘要时不推测新增篇数；服务重启的未完成任务显示“已中断”，不假装仍在运行，也不自动恢复付费请求。

## 持久化多轮问答

“证据与智能体 → 智能体问答”提供服务器保存的会话列表：问题提交时即保存，完整回答由后台线程自动落盘，不依赖网页是否还打开。刷新、切换页面、关闭浏览器或重启 Streamlit 后，选择同一会话即可继续；新会话不会混入其他会话的前文。会话可以重命名、归档/恢复，并导出完整 Markdown/JSON。归档不删除记录。

问答保存在统一数据目录的 `workspace\state\xps_agent.sqlite3`，使用新增的 `chat_conversations` / `chat_turns` 表，不覆盖 NF/RO、文献、证据或 ML 结果。每次模型请求带入同一会话最近最多 20 轮完整问答、最多 8 万字符，以及用户保存的长期研究备注（最多 6000 字符）。完整历史不裁剪；超出模型输入窗口的轮次在界面明确提示，重要目标、条件和证据/实验 ID 可放入长期备注持续保留。旧回答只能用于理解上下文，不能充当独立文献证据。

失败、取消、超时或服务重启中断时，保留原问题和状态，不伪造成功回答，也不自动重发。API 密钥禁止进入问题/备注，公开回答会过滤凭据；不保存模型私有推理正文。旧版已经消失的临时对话没有完整存档，不能可靠补回。

模型公式在问答、关系研究解读与膜分析文字中统一渲染。旧回答的 `\[...\]` / `\(...\)` 在显示时转成数学块/行内数学，带明显数学标记的裸方括号等也兼容；代码、链接和引用不改动。简单公式额外显示白话版；已知谱形变量的说明依据项目计算定义，不猜测未知符号。原始回答仍保存在数据库和 JSON 导出中；Markdown 导出采用兼容公式分隔符。此修复不需要重新调用模型。
